Anthropic Engineers Are Using A New Claude Code Prompting Trick...

youtuberesearchClaude Code

摘要

Anthropic 產品主管 Angela Jain 介紹 Claude Code「競賽模式」：啟動多個隔離 sub-agent 平行完成同一任務（如落地頁），再由 judge agent 盲評選最佳方案並可合併優點。實測 Night Owl 虛構產品落地頁，競賽版評分 91-93 優於單 agent 控制組，但耗時與 token 更高，適合高價值任務。

關鍵發現：多 agent 競賽+盲評可提升輸出品質，但應保留給重要專案。

適用情境：重要前端/文案需多角度比較、願意付出額外 token 成本時。
