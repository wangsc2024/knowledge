Claude Code Tutorial for Non-Coders

youtuberesearchClaude Code

摘要

Kevin Stratvert 教非工程師用 Claude Code（VS Code 擴充）建銷售管道 App：讀取 Excel、拖曳更新階段、自動備份，並連動共享資料夾結構。重點技巧含 Plan 模式先審計畫、@ 引用檔案、/rewind 回滾。對比 Cowork：Code 可跨資料夾、檔案可見性高，但機器權限更大需謹慎。

適用情境：業務／營運人員想把試算表流程產品化，且願意接受較少沙箱保護。
