偵察提案：sprix-sage-router

專案是什麼

wang2122/sprix-sage-router 是「屿智同行」平台下 Sprix AI 的路由元件，核心機制為 A2A（Agent-to-Agent）網絡提供狀態感知（state-aware）三態路由：SELF（自行處理）、COLLABORATE（協作）、HANDOFF（轉交）。成熟度、原始碼開放程度與維護活躍度均待查證，目前僅有簡短描述可參考。

對本系統的借鑑點

  • Cordis 插件 runtime 的任務派發邏輯可借鑑此三態模型：插件自身能完成的標記 SELF；需跨插件資料交換的標記 COLLABORATE；超出職責範圍的標記 HANDOFF，轉交給對應插件或回報人工，讓派發決策從隱性邏輯變成可追蹤的明確狀態。
  • todoist-team 已遷移的 33 項任務中，若存在跨任務依賴（例如晨間彙整需等待其他任務先完成），可用 COLLABORATE 狀態顯式標註依賴關係，取代目前可能靠執行順序隱性保證的耦合，降低 wrapper 合併後任務互相卡住的風險。
  • 個人知識庫查詢（knowledge-query skill）目前是單一來源的 API 呼叫。若未來擴充為多來源查詢（知識庫＋GitHub＋HN 等疊代蒐集流程），HANDOFF 可作為「本來源查無結果，轉交下一來源」的標準失敗轉移邏輯，取代現在可能需要的 if-else 硬編碼判斷。

建議行動

低風險：先查證該專案原始碼是否公開、授權條款為何，若可讀取則整理狀態機的實際實作方式（狀態轉換條件、如何避免循環轉交），寫成技術筆記存入知識庫，不變動任何現有系統。

需人工決策：是否要將此三態路由正式導入 Cordis 插件 runtime 的核心派發邏輯——這會觸及現有插件介面的非小幅改動，且該專案本身成熟度未經驗證，建議先以知識庫筆記形式觀察，待有更多 star／文件佐證其穩定性後，再評估是否納入實際架構。
