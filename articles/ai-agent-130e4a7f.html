AI Agent 在智慧醫療中藥物交互作用預測：多模態病歷與藥物資料庫整合分析

摘要

藥物交互作用（DDI）預測正從仰賴專家知識與實驗篩選，轉向以深度學習、圖神經網路（GNN）與多模態融合為核心的資料驅動模式[G3]。多篇研究顯示，結合分子結構、蛋白質標的與電子病歷（EHR）文本的多模態架構，搭配自適應模態選擇機制，可提升預測穩健度[G4][G2][G5]；EHR 端則仰賴整合式深度學習從非結構化病歷擷取藥物與不良反應關係[G6]。兩者串接正是智慧醫療 AI Agent 的核心骨幹，惟臨床可解釋性與工作流整合仍是關鍵瓶頸[G3]。

背景與現況

藥物交互作用長期是臨床藥理學的重大挑戰，可能削弱療效或引發嚴重不良事件；傳統偵測方法高度依賴實驗性檢測與專家判斷，成本高且難以規模化[G3]。隨著生醫資料快速累積，機器學習策略近年被大量導入 DDI 預測領域，深度學習架構、圖神經網路與精細的特徵工程明顯提升了預測表現，成為傳統方法之外可規模化、資料效率更高的替代方案[G3]。

值得注意的是，目前公開材料呈現出一個共同的技術路線群聚：至少三項獨立研究不約而同聚焦「多模態」建模，包括以 CNN-Transformer 混合架構處理 DDI 的 InfoMedex[G2]、以及兩項針對藥物-標的交互作用（DTI）的多模態表示學習研究——GRAM-DTI[G4] 與另一項發表於 Frontiers in Pharmacology 的多模態 DTI 研究[G5]。這種跨團隊的方法收斂，某種程度印證多模態融合已成為該領域的主流技術假設，而非單一團隊的孤立嘗試。同時，也有廣泛性文獻試圖梳理 AI 在藥物研發全流程（含廣譜藥物）中的應用地景[G1]，顯示 DDI/DTI 預測只是這條 AI 製藥管線中的一個節點，而非孤立問題。

在 EHR 端，另一條技術脈絡則聚焦於如何從真實世界的非結構化病歷文字中，擷取藥物與不良反應（ADE）之間的關係——n2c2（前 i2b2）挑戰賽相關研究即採用整合式（ensemble）深度學習方法完成此一抽取任務[G6]。這類工作雖然發表時間較早，但其目標——把自由文字病歷轉換成結構化的「藥物-事件」關係——正是任何以 EHR 為輸入的 DDI 預測 Agent 不可或缺的前處理環節。

機制與技術分析

多模態 AI Agent 若要同時運用 EHR 與藥物資料庫預測 DDI，技術上大致可拆解為三層機制，材料中各有對應的具體實作範例可供參照。

第一層是跨模態對齊與融合。GRAM-DTI 提出「Gramian Volume-Based Multimodal Alignment」，以體積（volume）為基礎的對比式損失函數，將藥物與蛋白質的多種模態表示（結構、序列、其他描述子）投影至共同的語意空間，取代傳統僅依賴 SMILES-蛋白質配對的作法，並將對齊機制擴展至四種模態[G4]。這種以幾何體積衡量多模態一致性的手法，比單純的向量拼接（concatenation）更能捕捉模態間的高階關聯，是目前多模態融合的一項技術亮點。

第二層是動態模態選擇與缺失容錯，這對真實醫療場景尤其關鍵——病患的病歷、檢驗數據、藥物結構資訊往往並非同時齊備。GRAM-DTI 的「Gradient-Informed Adaptive Modality Selection」透過梯度貢獻分析，動態判斷各模態對當前預測任務的邊際貢獻，再以自適應丟棄（Adaptive Modality Dropping）策略決定是否捨棄雜訊或低貢獻模態[G4]。此外，該框架也導入以 IC50 活性數值作為弱監督訊號的輔助雙模態對比損失，在標註稀缺時仍能有效訓練[G4]。這類機制若移植到 DDI/EHR 情境，等同賦予 AI Agent 在病歷資訊不全時仍能「降級運作」而非直接失效的能力。

第三層是臨床文本的結構化前處理。由於藥物交互作用的線索經常隱藏在醫師手寫紀錄或用藥醫囑中，n2c2 相關研究採用整合式深度學習模型，同時執行不良藥物事件（ADE）辨識與藥物-醫囑關係抽取[G6]，這與前述以分子結構為主的多模態模型形成互補——前者負責從「文字世界」萃取結構化實體，後者負責在「分子/藥理世界」建立交互作用的預測模型，兩者的輸出正是 AI Agent 融合模組的兩路輸入。

整體而言，npj Digital Medicine 的綜述特別指出，儘管深度學習與圖神經網路已顯著提升 DDI 預測的準確度，但模型可解釋性、跨資料集的泛化能力，以及與既有臨床工作流的整合，仍是阻礙其真正落地為「穩健、可解釋、可臨床操作」系統的三大障礙[G3]。這也是本節分析中最值得留意的技術瓶頸：多模態融合解決的是「輸入端資訊不足」的問題，但並未直接解決「輸出端如何被臨床醫師信任並採納」的問題。

應用與實務啟示

從實務角度看，一個可落地的 DDI 預測 AI Agent，其架構可對應材料中三類既有研究模組化拼接：（1）EHR 自然語言處理子代理，負責從病歷文本抽取用藥與不良反應關係，可參考整合式深度學習抽取模型的設計思路[G6]；（2）藥物知識/分子結構編碼子代理，運用 CNN-Transformer 或多模態表示學習框架處理藥物資料庫中的結構化與半結構化資訊[G2][G4][G5]；（3）融合與決策層，採用梯度資訊導向的自適應模態加權，在整合上述兩路異質輸入時，對缺失或低信度的模態自動降權，而非強制等權融合[G4]。

npj Digital Medicine 的綜述也提到，機器學習式 DDI 模型已在真實世界的藥物安全監測與治療決策支援中發揮作用[G3]，顯示這並非純學術構想，而是具備部署基礎的技術路線。對於個人化知識管理或開發實務而言，此處的啟示是：多模態融合架構的價值不在於單一模型的準確率提升，而在於它提供了一套「異質資料容錯」的設計範式——這對任何需要整合多來源、品質參差資料的 Agent 系統（不限於醫療領域）都具參考價值。同時，AI 在藥物研發全流程中的應用地景綜述也提醒，DDI 預測應被視為更大管線中的一環，設計 Agent 時宜預留與上下游模組（如藥物再利用、臨床試驗設計）對接的介面[G1]。

觀點與趨勢判讀

綜合材料可以看出兩個值得指出的判讀重點。第一，材料所呈現的技術收斂——多個獨立團隊各自提出多模態融合方案[G2][G4][G5]——本身就是一種信號，代表「單模態不足以支撐可靠的交互作用預測」已是領域共識，而非個別團隊的行銷語言，這使得多模態路線值得作為未來 Agent 設計的預設假設，而非可選項。

第二，也是本文認為最需要謹慎處理的一點：材料中真正針對「藥物-藥物」交互作用（DDI）且具體技術細節完整的案例其實有限，多數多模態技術細節（如 GRAM-DTI 的自適應模態選擇）是在「藥物-標的」交互作用（DTI）任務上驗證[G4][G5]，而非直接在 DDI 或 EHR 整合場景中被證實有效。將 DTI 上驗證的多模態融合技巧「移植」到 DDI/EHR 情境，目前仍屬合理推論而非既有實證——這是本報告在論述應用啟示時採取的類比路徑，讀者應將其視為技術可遷移性的推測，而非已完成驗證的結論。

第三個趨勢是，領域正從「預測準確率」轉向「臨床可用性」的目標函數轉移：npj Digital Medicine 綜述明確將模型可解釋性、泛化能力與臨床工作流整合列為未來研究方向[G3]，而非單純追求更高的 AUROC 或 F1 分數。這意味著下一代 DDI 預測 AI Agent 的競爭焦點，很可能不在於多模態融合技術本身的精緻程度，而在於能否把融合後的預測結果轉譯成醫師可理解、可追溯、可整合進既有處方系統的決策依據。真正決定此類 Agent 能否落地的，或許不是模型架構，而是可解釋性層與臨床工作流整合層的成熟度。
