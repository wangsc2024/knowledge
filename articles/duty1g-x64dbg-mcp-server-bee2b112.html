偵察提案：duty1g/x64dbg-mcp-server

專案是什麼

x64dbg-MCP Server 是內嵌於 x64dbg 除錯器的原生 MCP（Model Context Protocol）外掛，將除錯器原生 API（設中斷點、讀寫記憶體、控制執行流程）轉譯為標準 MCP tools，讓任何 MCP 相容 Agent（含 Claude Code）可直接呼叫除錯器功能。本質是「原生外掛 → MCP 協議橋接層」範例，star 數與穩定度待查證。

對本系統的借鑑點

  • Cordis 插件 runtime 現由 team-registry／plugin metabolism 機制管理插件進退場與生命週期，但插件能力僅供系統內部呼叫。可借鏡此案橋接層設計：為既有插件（如 website_curator_optimize）加一層 MCP Server 包裝，把核心動作暴露為標準 MCP tools，使 Claude Code 等外部 Agent 能直接調用，不必重寫插件邏輯。
  • 其「原生 API → tool schema」映射方式，可作為未來新插件設計介面規範：一開始就規劃哪些動作值得暴露為外部可呼叫工具，而非事後補接口。
  • 對 todoist-team／個人知識庫借鑑價值較低，除非未來需讓外部 Agent 直接操作任務佇列或筆記庫。

建議行動

低風險可先做：選一個穩定插件（如 website_curator_optimize）試作最小 MCP Server 包裝，驗證「插件動作→MCP tool」映射，不動現有 team-registry 呼叫路徑。

需人工決策：是否讓外部 Agent 具備直接觸發插件動作的權限——涉及授權範圍，以及進退場機制是否需對外部呼叫者同步生效，建議使用者先評估風險再決定是否開放。
