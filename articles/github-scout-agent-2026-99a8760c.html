GitHub Scout：Agent 架構（2026-07-17）

專案觀測摘要

agentscope-ai/agentscope（27952★ REST 觀測，pushed 2026-07-17）

分散式生產級多代理 runtime，強調 agent 行為可見/可理解/可信任。2.0 版新增：

  • 三態工具權限引擎（allow/approve/deny）：敏感工具強制 HITL 核准，統一 event bus 對外廣播 HITL 事件，屬 signal-based 與 handoff-based 混合模式。
  • AgentStateStore：支援 session 零停機復原（zero-downtime rolling deploy）。
  • StateModule 組合式 state_dict()/load_state_dict() 統一狀態序列化介面（2026-07-11 前輪已記錄，backlog_github_scout_20260711_103308992392 pending，本輪不重複）。
  • 2026-07 起支援 Daytona 沙箱 workspace 整合，multi-tenancy/multi-session 生產服務化。

agno-agi/agno（41200★ REST 觀測，pushed 2026-07-16）

AgentOS 為 agent 平台的 runtime + 控制平面，可將 agent 部署為服務並以 Web UI 管理。

  • session/memory/traces/human-approval 統一收攏於控制平面工作流層（屬 control-plane-approval／handoff-based 模式）。
  • 控制平面經瀏覽器直連使用者雲端環境，聲稱不經外部服務中轉資料。
  • 未見公開 session-recovery 或 zero-downtime 特化機制，與 AgentScope AgentStateStore 相比為明顯弱項。

改進提案

  1. [P1，已落實] review-policy 主題覆寫筆記補強：於 config/github-scout-review-policy.yaml → topic_overrides.agent_architecture.notes 補充本輪 REST 觀測發現（三態權限引擎、AgentStateStore、AgentOS 對照），供後續複核與提案溯源。version 3.0.7→3.0.8。
  2. [P2，待人工審查] 評估 AgentScope 三態工具權限模型（allow/approve/deny）強化 config/autonomous-harness.yaml 之 execution_contracts.human_review_gates.anti_stall_policy.auto_approve_when 粒度：本系統現為布林條件清單，對照三態 per-tool 粒度屬較粗模型。因涉及 guarded_operations 語意變更，需人工審查後方可實作。
  3. [P2，待人工評估] AgentStateStore 零停機復原模式對照本系統 state/run-fsm.json 之 Phase 2 中斷復原機制：本系統過往曾發生 run-fsm.json 狀態遺失導致 Phase 2 誤判死鎖之事故（已修復，非新缺口），建議評估「復原點快照 + 版本標記」機制降低同類事故重現機率。屬架構性變更，暫不立案為計畫。
