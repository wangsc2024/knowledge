GitHub Scout：MCP 參考實作與策展市集（2026-07-03）

專案觀測摘要

  1. modelcontextprotocol/servers（87,980★，pushed 2026-06-29，REST 即時觀測）— 官方 MCP 參考伺服器實作 monorepo。registry_model：每個 server 獨立子目錄含自身 README/manifest，屬 reference 實作而非 namespace 認證服務。curation_signal：純 stars／官方 org 背書，無自建排名演算法。adoption_scale：GitHub mcp-server topic 命中 15,926 個 repo（2026-05-24 觀測），本 repo 為事實標準參考點。
  1. modelcontextprotocol/registry（6,976★，pushed 2026-07-01，REST 即時觀測）— 社群驅動官方登錄服務。registry_model：聚焦 namespace 認證與 metadata hosting，實際安全掃描委由下游 aggregator/marketplace（關注分離設計）。curation_signal：本身不排名，僅供結構化 metadata 給下游策展層。adoption_scale：近 10K 官方公開登錄。
  1. punkpeye/awesome-mcp-servers（90,198★，pushed 2026-06-26，REST 即時觀測）— 社群策展 awesome-list，400+ 項目分 34 類，合計 1.2M stars。curation_signal：公開品質分數演算法，綜合 GitHub release/commit 活躍度、stars、listing age 自動計算排名（非純 star 排序）。同類 MCP Toplist 已覆蓋 73,547 個伺服器（2026-06-28 觀測），顯示策展市集已規模化。

改進提案

  • P1（已落實）：MCP 參考實作與策展市集為 SKILL.md 12 大搜尋主題之一，先前缺 topic_override，導致相關研究缺乏 registry_model/curation_signal/adoption_scale 結構化欄位。已於 config/github-scout-review-policy.yaml 新增 topic_overrides.mcp_reference_marketplace。
  • P2（待人工評估，未直接落實）：awesome-mcp-servers 的公開品質分數演算法（release/commit 活躍度 + stars + listing age 組合）與本系統 tools/asset_value_audit.py 打分邏輯相比，目前未明確納入 listing_age（資產首次登記至今天數）衰減維度。因 config/asset-value-targets.yaml 現處於多項優化觀察期（B-tier/A-tier cutover 進行中），本輪不直接改動評分公式，僅寫入 backlog 供後續人工複核。

審查結論

P1 提案：feasibility_score=9、stability_score=9（1 輪審查即通過，純新增 topic_override 區塊，不影響既有 topic_overrides 語意，YAML 已通過 yaml.safe_load 驗證）。低風險，直接落實。

P2 提案：因觸及正在觀察期的評分配置檔（B-tier/A-tier 優化 cutover），依 config/github-scout-review-policy.yaml 之風險判準列為 medium 風險，不自動執行，寫入 backlog 待人工複核。

已落實項目

  • config/github-scout-review-policy.yaml：新增 topic_overrides.mcp_reference_marketplace（含 required_project_fields、各欄位 expectations、review_notes 對照本系統四索引與 asset_value_audit）。

待人工審核項目

  • 評估是否於 config/asset-value-targets.yaml 補上 listing_age 衰減因子，對齊 awesome-mcp-servers 公開品質分數演算法維度；需待現行 B-tier/A-tier cutover 觀察期結束後再評估，避免與進行中的優化觀測互相干擾。
