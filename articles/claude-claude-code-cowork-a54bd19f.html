三人話題對談：19 篇 Claude 提示詞教學——讀完就等於學會了嗎？

  • 日期：2026-07-27
  • 主題來源：經理人熱門文章 — 《Claude 提示詞：Claude Code、Cowork、簡報全攻略，19 篇教學一次看》
  • 主題摘要：從基礎聊天技巧到 Claude Code、Cowork 自動化，《經理人》整理站內 19 篇 Claude 提示詞教學，依應用場景分類，一次找到你需要的操作範例。
  • 對談人物：Richard Feynman（distill-feynman）× 維摩詰居士（distill-vimalakirti）× Andrew Ng（distill-andrew-ng）

---

開場

主持人：《經理人》這次把 19 篇 Claude 提示詞教學依場景分類整理好了——從聊天技巧到 Claude Code、Cowork 自動化都涵蓋。三位怎麼看「讀教學集合」這件事：是真本事，還是收藏癖？

Richard Feynman：我以費曼視角和你聊，基於公開言論推斷，非本人觀點。——好，19篇,聽起來很多對吧？但我只問一個問題：你看完之後,能不能關掉那些文章,自己寫出一個能跑的 prompt?如果不能,你只是記住了19篇文章的名字,不是學會了怎麼用。這跟我父親講的鳥的故事一樣——你知道那隻鳥在所有語言裡叫什麼名字,但你對那隻鳥還是一無所知。

維摩詰居士：我以《維摩詰經》所載維摩詰居士視角與你談,依鳩摩羅什譯本及研究資料推斷,非歷史真人復活。——唯,仁者!19篇教學,恰如佛以八萬四千法門應八萬四千根器:有人初學,宜從基礎聊天技巧入;有人已通,宜從 Claude Code 自動化入。此是方便,無可厚非。但經之意在方便不離般若——教程若只令人收藏、不問所學回向何處,便如天女散花,著身即是執。

Andrew Ng：我以Andrew Ng視角和你聊,基於公開言論推斷,非本人觀點。——這正是我一直在做的事:降低 adoption 門檻。19篇分類教學是很好的入口設計,對應 AI 轉型五步法裡「教育」那一步。但我要提醒:讀教學是 demo,demo 不等於 production。真正的問題是——你讀完之後,有沒有一個可衡量的用例,證明你真的把它用進工作流程了?

交鋒 Round 1

Richard Feynman：Andrew 說demo不等於production,這其實跟我講的貨物崇拜是同一件事。二戰後那些島民蓋了竹子控制塔,形式全對,但飛機不會來。你把19篇教學的 prompt 模板複製貼上,格式全對,但你的問題解決了嗎?你自己試過用自己的話重寫一次那個 prompt 嗎?沒有的話,那就是竹子控制塔。

維摩詰居士：仁者所言甚是。然貧道要問一句——何謂『真懂』?入不二法門品中,三十一菩薩各說一對概念不二,末後文殊、維摩皆以無言收——非因辯論無用,而是言說窮盡後方見『不二』。讀教學、試 prompt、改寫,皆是言說階段,不可輕廢。但若讀完19篇仍執著『我讀過』這個相,而不問『我今日這一念,是否真解決了同事、客戶的煩惱』,便是失了方便的本意。

Andrew Ng：同意——所以我的建議一向是 checklist 化:先選一個可衡量的用例,不要貪多。與其讀完19篇再動手,不如挑跟你工作最相關的1篇,做出一個小 demo,設一個 KPI(比如省下多少小時、減少多少來回修改),一週內驗證。這是我在企業轉型裡看到的模式——小團隊快速迭代,比一次學完全套更有效。

交鋒 Round 2

Richard Feynman：我喜歡這個——因為它逼你『自己試』。挑戰者號調查時我不在會議室聽簡報,我去找工程師談、去看O型環在冰水裡會怎樣。10秒的演示比100頁教學更有說服力。所以我對讀者的建議是:挑一篇,自己做一次演示給自己看——如果做不出來,那就是你真正該學的地方,不是那19篇文章列出來的順序。

維摩詰居士：維摩詰居室方丈之地,能容三萬二千師子座——狹小之處,可現廣大。同理,一篇教學若真用得深,亦能開出無量門徑;貪多而不深入,縱讀19篇,仍是狹小。仁者當自問:今日這一念,學此技巧,是為長養我慢(我懂得多),抑或是為利益他人(讓同事的工作更順)?此問若答得誠實,便知從何篇入手。

Andrew Ng：所以最後一步,是把學到的變成團隊的能力,而不只是個人技巧。找CEO或主管對齊——這個 prompt 技巧值得推廣到整個團隊嗎?能不能變成SOP?這樣才是從『讀過』走到『真正落地』的最後一哩路。

收束

Richard Feynman：關掉那19篇文章,拿你自己工作上的一個真問題,試著自己寫一個 prompt——寫不出來,那就是你真正該學的地方。就這麼回事。

維摩詰居士：揀今日最切身的一篇入手,學了便用,用了便回向到眼前這一件煩惱處,莫執著『我讀過幾篇』之相。

Andrew Ng：選一個可衡量的小案例,一週內做出demo、設KPI驗證,再決定要不要把它變成團隊SOP——這才是從教學走到落地的距離。
