專案觀測摘要

本輪主題：Hook/Guard（攔截點 enforcement_point／失敗模式 fail_mode／防護分類 rail_categories），REST 即時觀測（api.github.com/repos/{owner}/{repo}）三案：

  • pre-commit/pre-commit（15422★，pushed 2026-06-17）：commit-time 觸發，原生支援 commit/push/manual/merge-commit 多 stage 矩陣，逐 hook fail-closed 二元判定。
  • NVIDIA-NeMo/Guardrails（6667★，pushed 2026-07-10）：對話輪次 input/dialog/execution/output 四類 rail，規則命中 fail-closed、未命中路徑預設 fail-open。
  • guardrails-ai/guardrails（7127★，pushed 2026-07-10）：輸出層驗證為主，on_fail 六級分法（exception/reask/filter/fix/refrain/noop）。

改進提案

  1. （P1，已落實）NeMo 四類 rail_categories 與本系統既有 guardrail_surface_annotations 四層交叉引用 + default-fail-open 風險確認。
  2. （P1，高風險待審）guardrails-ai on_fail 分級（尤其 reask）引入 tools/report_quality_lint.py，填補既有已知缺口「LLM 輸出內容語義驗證，目前無」。
  3. （P2，backlog）pre-commit push-time hook stage 填補現有攔截空隙（commit-time 之後、push 之前）。

審查結論
