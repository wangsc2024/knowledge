GitHub Scout：Agent 架構（runtime orchestration / state / HITL）

日期：2026-07-11｜主題選擇理由：LRU（Agent 架構上次 2026-06-25，16 天未搜）

專案觀測摘要

microsoft/agent-framework（12,020★，pushed 2026-07-10）

  • runtime_model：圖式編排，Executor 節點組 DAG，支援 sequential/concurrent/handoff/group 四模式；Semantic Kernel + AutoGen 合流繼任框架（2026-04 GA v1.0）
  • state_strategy：Durable checkpoint + resume，workflow.run(checkpoint_id=...)；遇 RequestInfoExecutor 等待輸入時自動落 checkpoint，含 pending request id；支援 time-travel
  • human_review_model：interrupt-point（同步短延遲），RequestInfoExecutor 暫停原地落 checkpoint，等回應後同一次呼叫續跑，語意近 LangGraph interrupt()
  • REST 觀測：curl https://api.github.com/repos/microsoft/agent-framework

agentscope-ai/agentscope（27,745★，pushed 2026-07-10）

  • runtime_model：事件驅動 ReAct 迴圈，統一 typed event bus；多代理走 Agent-as-a-Service 多租戶部署
  • state_strategy：StateModule 組合式狀態，state_dict()/load_state_dict() 可遞迴序列化整個巢狀代理階層；AgentStateStore 後端可插拔（記憶體/JSON/MySQL/Redis）
  • human_review_model：signal-based 為主（asyncio cancellation），中斷本身為 observable event，保留部分執行結果後可精確恢復；敏感工具呼叫前送 user-confirmation 事件
  • REST 觀測：curl https://api.github.com/repos/agentscope-ai/agentscope

改進提案

  1. [P1] RequestInfoExecutor checkpoint-on-pause（來源 microsoft/agent-framework）

- target_files: config/autonomous-harness.yaml, context/continuity/*.json, tools/planner_executor/runner.py

- 本系統 human_review_gates 為規則式靜態判定，review-only 命中時無標準化暫停現場快照，恢復易漏欄位/狀態漂移。建議借鑑：命中時序列化該次 phase 完整輸入為獨立 checkpoint 檔，review 完成後精確 resume。

- 審查結論：feasibility_score=8、stability_score=7，通過審查門檻（均≥7）；但因觸及核心執行引擎 tools/planner_executor/runner.py 且需搭配 ADR 定義 checkpoint schema，升為 risk_level=high，本輪僅輸出計畫至 docs/plans/github-scout-20260711-checkpoint-on-pause.md，不直接落實程式碼。

  1. [P2] StateModule 組合式狀態介面（來源 agentscope-ai/agentscope）

- target_files: tools/planner_executor/, state/.json, context/continuity/.json

- 現況 state/*.json 各自為政，無統一狀態物件抽象。已寫入 backlog 供常規優化評估。

  1. [P2] 中斷即事件（interrupt as observable event）（來源 agentscope-ai/agentscope）

- target_files: config/autonomous-harness.yaml, tools/self_heal/

- self_heal 命中 deny/pending 常整段視為失敗需重跑，可借鑑保留部分已完成輸出的設計。已寫入 backlog。
