三案分別代表本系統 config/autonomous-harness.yaml human_review_model 三大模式光譜：同步中斷（LangGraph interrupt）、多代理委派（CrewAI handoff）、非同步長時間掛起（Temporal signal）。CrewAI Flows 額外具備 @router 條件路由 + and_/or_ 事件匯聚的 DAG 編排能力，可對比 planner_executor 現行線性 phase 序列。

改進提案

  1. langchain-ai/langgraph｜細粒度 checkpoint + time-travel 回放（P1，medium effort）：借鑑逐步 checkpoint 粒度改善 planner_executor 狀態恢復，觸及核心執行流程建議走計畫。本輪不重複建單——已於 backlog_github_scout_20260616_220307721800（deferred）評估過，僅本輪重新確認 REST 星數。
  2. crewAIInc/crewAI｜@router 條件路由 + and_/or_ 匯聚（P1，medium effort）：擴充 config/routing.yaml Phase 1a 路由表達力，涉及核心路由行為建議先出計畫。本輪不重複建單——已於 backlog_github_scout_20260619_140750223718 與 backlog_github_scout_20260620_104521949814（均 deferred）評估過 3 次，僅本輪重新確認。
  3. temporalio/temporal｜signal-based 異步 human-in-the-loop（P2，high effort）：現行 human_review_gates 假設同步/短延遲審核；Temporal signal 機制可支援長時間掛起異步審核（審核者非即時在線情境）。新發現，已寫入 backlog backlog_github_scout_20260710_105733371389。因需引入獨立 Temporal server 依賴，effort=high，暫不直接落實程式碼變更。
