Anthropic's New Rules Break Most Claude Code Setups

youtuberesearchAnthropic Claude

Anthropic 技術人員 Tarik 說明 Claude 5 上下文工程新規則。痛點：system prompt、CLAUDE.md、skills 指令互相衝突，以及千行 CLAUDE.md 僅少數段落被用到卻全程載入，浪費 token 並拉低準確度。Anthropic 以 /doctor 審計 skills 與 CLAUDE.md，內部刪減約 80% system prompt 仍維持編碼評測。適用：升級 Opus 4.5→5、精簡 Claude Code 第二腦工作區、停用冗餘 skills。
