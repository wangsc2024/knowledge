三態 registry_model 7 天成長速率首次量化：零驗證門檻的 awesome-list（+708）遠快於建置+安全掃描閘門的 docker/mcp-registry（+6），驗證收錄門檻與生態擴散速度成反比。

新發現：第三方聚合平台 MCP Toplist（mcptoplist.com）以複合分數（version 數＋release/commit 活躍度＋stars＋listing age）跨 5 個來源（官方 Registry／Glama／Smithery／mcp.so／PulseMCP）做 meta-ranking，屬「registry 之上的跨來源排序層」，與既有三態模型不同層級。

改進提案

P2：對照本系統四索引（skills/tools/workflows/agents）現況——各自獨立盤點，tools/asset_value_audit.py 僅單一資產類型內打分，無跨資產類型統一 meta-ranking。因四索引本質異構（非同構列表），MCP Toplist 模式參考價值有限，本輪結論為僅觀察不建議引入，不建 backlog。
