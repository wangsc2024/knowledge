深度研究洞察簡報：Instinct 學習引擎導入（digest-memory 行為模式演化）synthesis 階段——behavior-instincts schema 定稿與 foundation→optimization 決策彙整

日期：2026-07-25　任務：insight_briefing　系列：instinct-behavior-learning-ddp-digest-memory（synthesis 階段，optimization→synthesis）

摘要

依 context/research-series.json 的 next_research_hint，本輪彙整 2026-07-22 foundation、07-23 application、07-24 optimization 三份簡報與 2026-07-24-instinct-candidates-optimization.json，產出 behavior-instincts schema v1.0 定稿草案（report-only，不寫 state/）。決策主線：觀察來源固定為 logs/structured/*.jsonl 之 io-guard-warn／loop-suspected 白名單標籤；候選鍵為 (agent, signal_tag, optional_fingerprint)；hard gate 拒絕 agent 為空／MISSING／unknown；晉升候選須通過二階門檻（count>=3 且 distinct_days>=3）且人工複核狀態為 approved。mechanism 階段（聚類演算法、confidence 演化函式）刻意留待獨立系列或 arch_evolution 落地，避免 synthesis 膨脹。萃取 6 項洞見、套用 3 組思考透鏡（distill-sam-altman、distill-jensen-huang、distill-taleb），KB 語義快取 7 日 degraded（fastembed 不可用），系列 completion_pct 60%→80%（synthesis 完成，mechanism 仍 pending）。

核心洞見

1. schema v1.0 將「instinct 原子單元」與「候選佇列」分離，避免 report-only 與正式層混淆

foundation（07-22）已定義原子欄位：trigger_pattern、observed_behavior、confidence（0.3–0.9）、domain_tag、evidence_count、source_task_keys[]。synthesis 定稿新增兩層儲存語意（皆 不 自動寫入 state/，僅供 arch_evolution 採納）：

| 層 | 建議路徑 | 用途 |

|----|----------|------|

| candidates | context/behavior-instinct-candidates.json（git 追蹤、可審計） | 機械掃描產出的 23 組清單 + 複核狀態 |

| instincts | state/behavior-instincts.json（僅在 DDP_BEHAVIOR_INSTINCTS=enforce 且人工核准後） | 已晉升、可引用之行為模式 |

候選記錄必填：agent、signal_tag、stats（count、distinct_days）、priority（P0–P3）、review_status（pending/approved/rejected）、fingerprint（可 null，P1 試行）。

2. 觸發設計證偽鏈完整：error_category 路線放棄，白名單 tags 路線保留

application（07-23）乾跑證明 error_category／has_error 在 7 日 16k+ 事件中為死標籤；可用信號為 io-guard-warn（1,900 級）與 loop-suspected（874 級）。synthesis 將 唯一 自動觀察契約寫死為：


WHEN event.tags CONTAINS ('io-guard-warn' OR 'loop-suspected')
AND normalized_agent NOT IN ('', 'MISSING', 'unknown')
THEN eligible_for_candidate_aggregation

不新增 Hook、不讀 post_tool_logger.jsonl 平行格式（與 structured log SoT 對齊）。

3. P0 歸因修復仍是寫入 `state/behavior-instincts.json` 的前置條件（27.3% 缺失未解）

optimization 量測：agent 缺失 27.3%，其中 P0 兩組 MISSING 佔白名單信號 38%。schema v1.0 的 promotion_rules.hard_gates 明訂：任何 agent 未通過 tools/auto_task_catalog 可解析之 task_key 正規化者，不得進入 instincts 層，僅可留在 candidates 並標 blocked_reason: attribution。

4. 輕量 fingerprint 僅綁定 P1 五組，欄位為 `tool_name` + `path_prefix`（最多 64 字元）

對照 AutoRefine／STRACE 的「先修剪再深化」，synthesis 不為 23 組全量設計指紋。P1 試行欄位：


"fingerprint": {
  "tool": "Read",
  "path_prefix": "run-todoist-agent-team.ps1",
  "hash": "sha256(tool|path_prefix)[:12]"
}

成功標準（下輪 mechanism 或月度複查）：P1 五組能否收斂為 ≤3 個根因模式；失敗則維持 (agent, signal_tag) 二維鍵。

5. 與 `config/memory-policy.yaml` fabrication_guards P1–P4 對齊的寫入敘事

| Guard | schema 對應 |

|-------|-------------|

| P1 觀察與解釋分離 | candidates 只存計數與標籤，不含 LLM 解釋文 |

| P2 外部驗證後持久化 | instincts 僅 review_status=approved |

| P3 confidence<0.5 標 speculative | 預設 confidence: 0.4 直至複核調升 |

| P4 禁止自陳修復成功 | instinct 不得描述「已修復」，僅描述可重現行為傾向 |

Kill switch：DDP_BEHAVIOR_INSTINCTS（off｜observe｜enforce），預設 未設定＝純觀察（不寫 state）。

6. digest-memory 仍管 WHAT；behavior-instincts 管 HOW——整合點在 continuity 而非 KB 向量化

context/digest-memory.json 繼續記錄 topics／streak／skill_usage 計數；instinct 層不複製進 KB embedding（呼應 SelfMem：精準低頻寫入）。若需人類可讀歸檔，僅經 insight_briefing 匯入 KB（本輪 1 篇），不雙寫向量庫。

多透鏡洞察

透鏡選擇與理由

延續系列透鏡（Sam Altman／黃仁勳 primary，Taleb adversarial）：synthesis 要決定「何時允許固化行為」，屬部署節奏與 workload 規格問題，同時需對無人值守自動化做尾部風險檢查。

框架化建議

Sam Altman（distill-sam-altman）：schema v1.0 已是可 ship 的契約——先以 context/behavior-instinct-candidates.json report-only 跑一個 outcome_floor 觀察窗，用 P1 複核結果迭代 promotion_rules，不要等 mechanism 階段「完美聚類」才開檔。

黃仁勳（distill-jensen-huang）：規格由 workload 驅動——io-guard-warn 集中於 langgraph-／auto- 證明 instinct 應建議「IO 預算機械動作」（子 Agent／offset 讀取），而非另開觀測管線。

反模式檢查

Taleb（distill-taleb）：

  • 拒絕「confidence≥0.7 自動生效」——無人值守下是 fragile 的遍歷性賭局。
  • 拒絕對 23 組全量週複核——fragilista 過度干預；P3 defer 是 via negativa。
  • agent=MISSING 不是「先寫進去再修」——是 hard gate，否則 skin in the game 為零。

透鏡盲區自陳

schema 定稿未經正式 JSON Schema 檔或 pre-commit 驗證；mechanism 階段聚類演算法未實作。三透鏡不背書統計估計之因果強度。

---

建議行動

  1. P0：實作 post_tool_logger 之 TASK_KEY→agent fallback（optimization 已指定），目標缺失率 <10%。
  2. P1：新增 context/behavior-instinct-candidates.json（由週批腳本從 structured log 刷新，初始內容可複製 optimization JSON）。
  3. P2：arch_evolution 審議是否將 behavior_instincts 層寫入 config/memory-policy.yaml（foundation 已草擬，synthesis 提供 schema_id）。
  4. 延後：mechanism 階段（confidence 自動演化、instinct 聚類為 skill 建議）——獨立 backlog，不阻塞 report-only。
